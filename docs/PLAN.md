# Ебись оно конём — план

Исходный план Android-версии — как приложение строилось по шагам. Сейчас проект открытый, релизы — на GitHub.

## Стек

- Kotlin 2.1 + Jetpack Compose (Material3 только для системного выбора даты)
- minSdk 26 (Android 8.0+), targetSdk 35
- Хранение: JSON-файл во внутренней памяти приложения (`files/tasks.json`). Для личного списка на сотню задач Room не нужен, а сборка проще.
- Сборка: release APK, подписанный debug-ключом. Release, а не debug, чтобы Compose-анимации не тормозили.

## Этапы

1. **Каркас проекта** — Gradle, манифест, тема, шрифты (Unbounded, Onest, JetBrains Mono), иконка «конь-чекбокс». ✅
2. **Графика** — ржущий конь и логотип как VectorDrawable (перенесены из прототипа 1:1). ✅
3. **Данные** — модель задачи, сохранение в JSON, ViewModel: добавить / отметить / удалить. ✅
4. **Экран приветствия** — «Ну здарова, бедолага», кнопки «поРАБотать» / «поплакать», уезжает с анимацией. ✅
5. **Трекер** — шапка «Ебись оно 🐴» падает с пружинкой, вкладки Сегодня / Вся херня / Сделано, карточки, галочки, «нахер», пустые состояния, тосты. ✅
6. **Форма** — «Новая херня», дата: Сегодня / Завтра / своя (календарь) / Никогда → конь «Размечтался» + вибрация. ✅
7. **Сборка APK** — JDK 17 + Android SDK + Gradle в `%LOCALAPPDATA%\EbisToolchain`, `ebis-ono-konem.apk`. ✅
8. **Уведомления** ✅
   - Утренний пинок (9:00, настраивается): сколько задач, сколько протухло. Кнопка «Отъебись на сегодня».
   - Дневное нытьё (0–3 раза: 14:00 / 12:00+17:00 / 12:00+15:00+18:00) про самую старую задачу, с прогрессом. Кнопки «Сделал», «Завтра, честно», «Отъебись на сегодня».
   - Позорный столб (11:00) про самую протухшую задачу, тон зависит от срока, юбилеи на 100/200/365… дней. Кнопки «Сделал», «Завтра, честно», «Нахер».
   - Вечерний итог (21:00, настраивается).
   - Поздравление, когда закрыта последняя задача на сегодня (раз в день).
   - Экран настроек (🔔 в шапке), тестовая отправка каждого типа, подсказка про экономию батареи.
   - Точные будильники (`USE_EXACT_ALARM`), перевыставляются после перезагрузки и смены времени.
9. **Тема и анимации** ✅
   - Ночная тема AMOLED: чистый чёрный, белые рамки, красные тени, жёлтая шапка. Смена темы перетекает цветами.
   - Общий ритм движения в `Motion.kt`. Галочка рисуется штрихом, текст зачёркивается, карточка уезжает вбок.
   - Вкладки перелистываются, под ними едет индикатор, счётчики крутятся как табло. Карточки въезжают лесенкой.
   - Шторка на пружине со смахиванием вниз; системный жест «назад» с предпросмотром (Android 14+).
10. **UX** ✅
   - «Верни» в тосте после «сделано», «нахер», переноса и правки.
   - Свайп вправо — сделал (в «Сделано» — вернуть), влево — на завтра. Тап по карточке — правка, долгий тап — перетащить (в «Сегодня»).
   - «Вся херня» по группам: Просрано / Сегодня / Завтра / На неделе / Потом. «Сделано» по дням + серия и рекорд.
   - Ярлык «Накинуть» на иконке, «Поделиться» текстом из любого приложения, приветствие можно выключить.
11. **Фичи** ✅
   - Повторы: каждый день / по будням / каждую неделю / каждый месяц. Сделал — появляется следующая.
   - Разбор из названия: «завтра в 15:00», «в пт», «через 3 дня», «25 окт», «каждый понедельник», «срочно». Тесты: `QuickParseTest`.
   - Напоминалка на время задачи (канал «Напоминалки по задачам»), кнопки «Сделал» / «Через час» / «Завтра».
   - Бэкап в JSON-файл и загрузка обратно (настройки → 💾).
   - Серия дней, когда закрыто всё; рекорд — с поздравлением. «Горит» 🔥 — всегда наверху.
12. **Потом, если захочется** — виджет на рабочий стол.

## Поведение

- Приветствие показывается при каждом запуске и если приложение было свёрнуто больше 5 минут.
- «Сегодня» = задачи на сегодня + просроченные.
- При первом запуске есть две задачи-обучалки, их можно удалить кнопкой «нахер».

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл: `ebis-ono-konem.apk` в корне проекта. Скинуть на телефон, открыть, разрешить установку из неизвестных источников.
